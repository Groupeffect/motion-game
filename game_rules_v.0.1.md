# Game Rules – xxNamexx

## Overview

**Objective:** Make your opponents' smartphones shake – without moving your own device. The last remaining player or team wins.

> ⚠️ **Note:** This game requires access to the smartphone's motion sensor (gyroscope/accelerometer).

---

## Setup

1. **Create a game:** The game host taps **"New Game"**, assigns a **game name** and a **password**.
2. **Choose a mode:**
   - **Team Mode:** 2–10 teams
   - **Free-For-All:** No teams, every player is solo.
3. **Host name & handicap:** The host enters their player name and sets their own **handicap** (0–100).
   - *Handicap* = sensitivity of your own sensor. The higher the value, the more sensitive the sensor reacts.

---

## Joining the Game

- Players tap the game name in the **lobby** and enter the **password** – or type the game name directly into the input field.
- Each player selects their **team** and enters a **name**.
- The **handicap** set by the host is displayed (default: **50 / 100**, adjustable via slider).

---

## Game Flow

| Step | Action |
|------|--------|
| 1 | The host taps **"Start"** (minimum 2 players required). |
| 2 | **Countdown: 5 seconds** – the game is then locked (no more players can join). |
| 3 | **Rest phase:** All players place their smartphone down. |
| 4 | The host taps **"Start"** again. |
| 5 | **Countdown: 5 seconds** (with beep sound on all devices) – the game begins. |

---

## Health Points

- Every player starts with **100 HP**.
- **HP Loss:** The stronger the vibration and the higher the handicap, the more HP are deducted.
- **HP Regeneration:** When the smartphone is at rest, HP slowly regenerate bit by bit.
- **Eliminated:** At **0 HP**, a **2-second continuous tone** sounds – the player is out of the game.
