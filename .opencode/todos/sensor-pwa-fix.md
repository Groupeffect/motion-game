# Sensor Access & PWA Fix Plan

## Goal
Ensure `index.html` standalone game and `frontend/` Vue app work correctly with sensor access and permissions in PWA mode (installed) or when built on GitHub Pages.

---

## Issues Found

### Standalone `index.html` (attached)
1. **Missing Permissions-Policy meta tag** — browsers may block accelerometer without it
2. **No PWA manifest link** — can't be installed on device
3. **No theme-color meta** — poor PWA appearance
4. **No service worker** — no offline cache / installability

### `frontend/` Vue App
1. **No `service-worker.js`** in `public/` — registration silently fails
2. **No `manifest.json`** — PWA plugin has no manifest to build
3. **No `pwa` config in `vue.config.js`** — plugin defaults are barebones
4. **No Permissions-Policy** — headers or meta tag missing
5. **`SteadyHandsGame.vue` has unused `handleMotion()` method** — dead code
6. **`registerServiceWorker.js` references `${process.env.BASE_URL}service-worker.js`** — never exists

---

## Fixes (Standalone `index.html`)

### 1. Add Permissions-Policy meta tag
```html
<meta http-equiv="Permissions-Policy" content="accelerometer=(self)">
```

### 2. Add PWA manifest link
```html
<link rel="manifest" href="manifest.json">
```

### 3. Add theme-color meta
```html
<meta name="theme-color" content="#0d1117">
```

### 4. Create `manifest.json`
Standard PWA manifest for "Steady Hands" game with:
- name: "Steady Hands"
- short_name: "SteadyHands"
- start_url: "."
- display: "fullscreen" or "standalone"
- background_color: "#0d1117"
- icons (from frontend/public/img/icons/ — use existing ones)

### 5. Create `sw.js` (Service Worker)
Basic cache-first SW for:
- Cache HTML, CSS (inline), JS (inline)
- Fallback to cache on network error
- Versioned cache for busting

## Fixes (`frontend/` Vue App)

### 1. Add PWA config to `vue.config.js` ✅ DONE
Configure `@vue/cli-plugin-pwa` with:
- `name: "Steady Hands"`
- `themeColor: "#0d1117"`
- `msTileColor: "#0d1117"`
- `registerType: 'register'` — uses manual SW registration via `registerServiceWorker.js`
- `manifestOptions` with icons from `public/img/icons/`
- `workboxOptions` for proper caching

### 2. Service worker auto-generated by PWA plugin ✅ DONE
- Workbox precaches all JS, CSS, HTML, manifest, robots.txt
- Generated at `docs/service-worker.js` in build output

### 3. Manifest auto-generated by PWA plugin ✅ DONE
- Generated at `docs/manifest.json` in build output
- Icons: 192x192, 512x512, plus maskable variants

### 4. Add Permissions-Policy meta to `public/index.html` ✅ DONE
```html
<meta http-equiv="Permissions-Policy" content="accelerometer=(self)">
```

### 5. Wire sensor data flow in mixin ✅ DONE
- `gameMotion.js` `handleMotionData()` now calls `this.onMotionData(acc)` when fresh data arrives
- `SteadyHandsGame.vue` provides `onMotionData(acc)` to receive and process sensor data

### 6. Remove dead `handleMotion()` from `SteadyHandsGame.vue` ✅ DONE
- The old `handleMotion(event)` was never called — the event listener used `handleMotionData` from the mixin
- Replaced with proper `onMotionData(acc)` callback pattern
